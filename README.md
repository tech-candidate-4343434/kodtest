# Gästbok – Kodtest

Ett enkelt kodtest. Du **måste** använda **Docker**, **HTML/CSS**, **SQL** och **Git**.  
Du får välja valfritt programmeringsspråk.

---

## 🎯 Mål
Bygg en minimal gästbok:

- `GET /` visar lista + formulär.
- `POST /entries` tar emot `name` (1–50) och `message` (1–500) och sparar i SQL.
- Kör allt via **Docker Compose**.
- Använd **Git** med **3–6 meningsfulla commits** (inte en enda stor commit).

---

## 🛠 Uppgift – detaljer
- Implementera `GET /` och `POST /entries`.
- Validera längder, **escapa output** och sortera poster nyast först.
- Skriv ren **HTML/CSS** (ingen JavaScript krävs).
- Commit(a) i **små steg** med tydliga meddelanden (3–6 commits).
